# licencas

Lista de licenças canceladas dos programas da OS Solution.

- `canceladas.txt` é uma lista **assinada digitalmente**. Ela traz só códigos (hash) de licenças ou de computadores: nenhum nome, CPF, CNPJ ou outro dado de cliente.
- Os programas baixam este arquivo para conferir se a licença continua valendo. Nada é enviado de volta.
- O arquivo é gerado pelo Cancelador de Licenças. **Não edite à mão**: qualquer mudança invalida a assinatura e os programas ignoram a lista.
- **Não apague, não renomeie e não torne privado este repositório.** Os programas instalados dependem deste endereço.
